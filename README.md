# NativeCall Italia — лендинг вакансии Sales Manager

Одностраничный сайт вакансии (итальянский язык). Сейчас размещён на **https://netivcalllproserv.com**.

Весь сайт — один файл `index.html`: разметка, стили, форма заявки, Meta Pixel. Сервер, PHP и база данных не нужны.

## Как работает форма заявки

1. Кандидат заполняет форму и нажимает **«Invia la candidatura»**.
2. Форма проверяет поля (имя и фамилия, телефон ≥ 8 цифр, ответы на все вопросы, согласие).
3. Заявка отправляется в Google Форму (`navigator.sendBeacon`, запасной вариант — `fetch` no-cors),
   привязанную к Google Таблице «Лиды Италия», лист «Ответы на форму (1)».
4. После успешной отправки — событие Meta Pixel (см. ниже) и экран «Grazie!».

Код отправки: функция `sendToSheet()`, адрес и ID полей формы — `GOOGLE_FORM_ACTION` и `GOOGLE_FORM_FIELDS`.

## Meta Pixel — ID `2150312056363717`

| Событие | Когда отправляется |
|---|---|
| `PageView` | при открытии страницы |
| `Lead` (стандартное) | нажата кнопка «Invia la candidatura», форма прошла проверку, заявка отправлена **и** на все 4 вопроса ответ «Sì» |
| `LeadNotQualified` (пользовательское) | заявка отправлена, но хотя бы один ответ «No» |

4 квалифицирующих вопроса (`QUALIFYING_QUESTIONS`):
- `35_ore_settimana` — может работать 35+ часов в неделю
- `computer_internet` — есть компьютер и стабильный интернет
- `esperienza_clienti` — опыт в продажах / обслуживании / поддержке клиентов
- `esperienza_bellezza_salute` — опыт продаж товаров для красоты и здоровья

Параметры события: `content_name: "Sales Manager Italia"`, `contact_method`, `qualified: yes|no`, плюс `eventID` (для дедупликации, если позже подключат Conversions API).

**Для оптимизации кампании выбирайте событие `Lead`.** Место конверсии в объявлении — «Сайт», ссылка на домен с этим `index.html`.
Если в кампании используются «Мгновенные формы» (Instant Forms), заявки остаются в Facebook и на сайт / в таблицу не попадают.

## Метки источника в таблице

Столбец **UTM** содержит:
- `utm_source=… | utm_campaign=… | …` — UTM-метки из ссылки;
- `fbclid` — человек пришёл по клику на рекламу Facebook/Instagram;
- `browser=FB/IG app` — заявка отправлена из встроенного браузера Facebook/Instagram.

Столбец **Страна** — язык браузера посетителя (например, `it-IT`).

## Как проверить

1. Открыть сайт с меткой, например `https://netivcalllproserv.com/?utm_source=test`.
2. Заполнить форму, на все 4 вопроса ответить «Sì», нажать «Invia la candidatura».
3. Через несколько секунд в таблице появится строка, в Events Manager → «Тестовые события» / «Обзор» — событие `Lead`.

## Размещение

Загрузить `index.html` (и при желании `robots.txt`) в корень сайта на хостинге. Нужен HTTPS.
Логотип и фото загружаются с CDN NativeCall (`static.tildacdn.net`).

**Не удаляйте и не переименовывайте вопросы в Google Форме** «NativeCall Italia — candidature (сайт)» — сайт привязан к их ID.
